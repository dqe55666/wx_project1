# 医护/陪护上门预约小程序（护理版）
1
当前实现用户下单、员工 Web 接单与用户评价闭环：

- 管理端维护医院单位、员工和商城商品数据
- 小程序获取医院单位、服务项目
- 小程序获取用户定位并显示到医院单位的距离
- 用户填写预约信息并提交订单
- 后台维护员工档案，员工通过 Web 工作台接单
- 用户可在服务完成后对订单评分和评论
- 后端使用 FastAPI + MySQL 保存医院、服务项目、商品和订单

## 后端启动

1. 创建 MySQL 数据库：

```sql
CREATE DATABASE IF NOT EXISTS care_booking
  DEFAULT CHARACTER SET utf8mb4
  COLLATE utf8mb4_unicode_ci;
```

2. 安装依赖并启动：

```bash
cd backend
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

如果 MySQL 账号密码不是默认值，修改 `backend/.env` 里的 `DATABASE_URL`。
如果 `backend/.env` 已经配置过真实密码和高德密钥，不要再次执行 `cp .env.example .env`，否则会被示例占位值覆盖。
后端启动时会自动创建 `care_booking` 数据库和初始表。用户账号档案（姓名、手机号及订单关联）、医院、服务项目、商品、商城订单、陪诊订单和客服消息均由 SQLAlchemy 持久化到 MySQL；旧版本数据库会在启动时自动补齐 `customers` 表和订单关联字段。
定位地址解析由后端代理高德 Web 服务，配置 `backend/.env`：

```    呢      31232】、
AMAP_KEY=你的高德Web服务Key
AMAP_PRIVATE_KEY=你的高德Web服务安全密钥
STAFF_TOKEN_SECRET=生产环境随机密钥
```

## 管理端

后端启动后访问：

```text
http://127.0.0.1:8000/admin/
```

管理端打开后必须先登录。默认管理员账号为 `admin`，密码为 `123456`，可在 `backend/.env` 中通过 `ADMIN_USERNAME`、`ADMIN_PASSWORD` 修改。登录令牌由后端签名并有有效期，所有 `/api/admin/*` 接口都会校验令牌。

可以新增、编辑、停用医院单位和员工，也可以查看最近订单与接单员工。小程序首页会从 `/api/hospitals` 获取这些单位。
管理端支持用高德检索医院单位：

- 点击“定位搜附近30km”会使用浏览器定位，搜索当前位置周边医院
- 输入医院名称后点击“按名称搜索”可检索医院
- 点击搜索结果里的“填入”会把名称、地址、坐标、电话填到单位表单

管理端的“商品管理”可新增、编辑、上/下架商品，并维护分类、售价、库存、图标与详情描述。上架商品会同步显示在小程序商城；库存为 0 时标记为缺货。小程序会创建真实的待付款商城订单，支付确认时才原子扣减库存并更新销量；订单商品、价格和数量会保存为订单快照。

管理端的“漂流瓶管理”可查看、删除或单独隐藏发帖内容，并可恢复隐藏帖子。隐藏只改变 MySQL 中的 `status`，不会删除记录；小程序公开列表只显示 `published` 内容。预审核默认关闭；开启后新发内容必须在后台通过审核才会公开显示。没有可交互式公网备案时建议开启该功能。

## 员工 Web 工作台

后端启动后，员工访问：

```text
http://127.0.0.1:8000/staff/
```

管理员为每位员工设置唯一的员工 ID，员工使用该 ID 和初始密码 `123456` 登录。登录后可查看待接订单、领取订单；接单后自动切换到“已接订单”，开始工作后自动切换到“工作中”。员工在预约时长未满时申请结束，系统会先通知客户协商确认；客户同意后订单才会完成。管理员新增员工时会自动创建同样的默认密码。

员工在接单后会自动请求浏览器定位，并每 15 秒同步一次位置。员工工作台在正式环境必须通过 HTTPS 访问，浏览器才能提供定位权限。

管理端可为员工设置抽成比例，默认 `85%`。订单完成时会保存该员工当时的抽成比例和结算收入；之后调整员工比例不会影响已完成订单。每一笔完成订单会自动生成一条员工收入记录，员工工作台“收入”页可查看待提现余额、累计收入和关联订单的入账明细。后台可修改已有评价内容；“确认完成”会按比例结算员工收入，“强制结束”会停止订单且不结算本单收入。

## 客服与反馈

管理端新增或编辑员工时可选择“客服”角色。后端会预置客服账号 `KF1001`，初始密码为 `123456`。客服登录后访问：

```text
http://127.0.0.1:8000/support/
```

小程序“我的”中的“在线客服”和“意见反馈”都会创建客服工单，客服可领取工单、在线回复和办结。客服可在工作台按订单 ID 强制停止订单，系统会向客户的订单会话发送处理通知，且该订单不会结算员工收入。客服账号不能接取陪诊订单、更新陪诊位置或查看员工收入。

## 小程序端

用微信开发者工具打开项目根目录。默认接口地址在 `app.js`：

```js
apiBaseUrl: 'http://127.0.0.1:8000'
```

本地开发时如果请求被拦截，需要在微信开发者工具里关闭“校验合法域名、web-view、TLS 版本以及 HTTPS 证书”。

小程序不会直接请求高德，正式环境只需要把你的后端 HTTPS 域名配置为微信小程序 `request` 合法域名。进行中的订单详情会展示实时位置，员工位置由员工工作台每 15 秒上传；客户需允许位置权限，才会在地图中展示自己的当前位置。

## 用户预约与评价

小程序首页可提交预约并在“我的预约”查看本机创建的订单。服务人员完成工作后，用户可以提交一次 1 至 5 分评分和评价内容；后台订单列表会展示该评价。
