## 08:26 加启动登录闸门（未登录自动进登录页）

用户要求「启动就连登录页」。

### 实现
`app.js` 新增全局方法 `App.ensureLogin()`：
- `globalData.loginPrompted` 标记**本次启动是否已提示过**，只提示一次
- 已登录（`userInfo.nickName && avatarUrl`）直接返回，不跳转、不闪屏
- 跳转放在 `wx.nextTick` 里（降级 `setTimeout 0`），避免 onShow 时页面还没 ready
- `setUserInfo()` 里把 `loginPrompted` 置 true；`clearUserInfo()` 里置回 false（退出登录后下次还会提示）

`pages/index/index.js` 新增 `onShow() { getApp().ensureLogin() }`。

### 为什么不用别的方案
- **不放 `app.onLaunch`**：那时没有页面栈，`navigateTo` 会 fail
- **不把 login 设成 app.json 首页**：已登录用户会先闪一下登录屏再 switchTab，体验更差
- **不做成全局拦截**：分享卡片直接打开详情页时不该被登录页打断

### 当前行为
冷启动未登录 → 首页渲染一帧 → 登录页滑入 → 登录成功/先随便看看 都 `navigateBack` 回首页，本次启动不再提示；下次冷启动若仍未登录会再提示一次。

### 预览
`mockups/login-preview.html` 顶部加了「播放启动动画」按钮（panel 用 `@keyframes slideUp` 重播），可直接看滑入效果。
